核心功能

📋

剪切板历史

自动记录所有复制内容，支持文本、图片、代码、颜色、URL 等类型，随时找回历史记录。

🔍

智能搜索

模糊搜索快速定位历史内容，支持按类型、来源应用、标签筛选，键盘全程操作。

⚡

快捷键召唤

按 Shift+Cmd+V 即可唤起剪切板面板，不打断工作流，数字键 1-9 快速粘贴。

✨

代码高亮预览

使用 VS Code 引擎（Shiki）对代码片段语法高亮，JSON 自动格式化，颜色可视化预览。

🛡️

本地隐私优先

所有数据存储在本机 SQLite，不上传任何内容。支持可选的 iCloud Drive 多设备同步。
