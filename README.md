## 功能特性

📋 **剪切板历史** — 自动保存每一次复制，文本、图片、代码、颜色、链接全都记录

🔍 **快速搜索** — 模糊搜索 + 数字键 1-9 快速粘贴，全程键盘操作不离手

⚡ **全局快捷键** — `Shift+Cmd+V` 随时唤起面板，不打断当前工作流

✨ **智能预览** — 代码语法高亮、JSON 格式化、颜色色块、Base64 解码即时预览

🛡️ **本地优先** — 所有数据存在本机，不联网、不上传，可选 iCloud 多设备同步

## 快速上手

1. 下载 `.dmg` 文件，将 **Stash** 拖入 **Applications** 文件夹
2. 首次启动时，按提示授予「辅助功能」和「输入监控」权限
3. 按 **`Shift+Cmd+V`** 唤起剪切板面板，开始使用

📖 更详细的说明请查看 [使用文档](https://perseveringman.github.io/Stash/)

## 系统要求

- macOS 12 Monterey 或更高版本
- Apple Silicon 或 Intel 处理器
