# Stash 2.0.0 runtime screenshots

Captured from the signed native Swift release build on macOS 26.5, using an isolated QA profile and synthetic clipboard entries. No production clipboard history is shown. The app was compiled with Swift 6.3.1 and macOS SDK 26.4.

- central-light.png: central split layout and formatted JSON preview.
- central-dark.png: central split layout and native code preview.
- bottom-dark.png: horizontal cards with text, JSON, code and color previews.
- side-dark.png: side panel with compact filter menus and JSON detail.
- settings-light.png: native Settings navigation, controls and unified light appearance.

Screenshots are direct application captures, not mockups. Demo settings intentionally use unlimited retention and item count. The release defaults remain 30 days and 2000 items.
