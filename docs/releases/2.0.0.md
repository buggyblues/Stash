# Stash 2.0.0

Stash 现已全面切换到 Swift / SwiftUI / AppKit 原生 macOS 实现。Electron 1.x 已废弃，不再维护或发布。

- macOS 26 原生 Liquid Glass，旧系统使用 Vibrancy 回退。
- 中央分栏、右侧面板和底部卡片，配合搜索、类型/来源/标签筛选。
- 原生设置导航，标题栏、侧栏和正文统一跟随浅深色外观。
- 文本、图片、代码、JSON、URL、颜色、Base64 和路径预览。
- 键盘驱动的快速粘贴、序列队列、批量粘贴与桌面小组件。
- 本地 SQLite 数据，可选 iCloud Drive 同步。
- 移除模板功能；不包含密码保险库、Touch ID 或 TOTP。

提供 Developer ID 签名、公证后的 Apple Silicon 与 Intel DMG/ZIP 安装包。首次跨应用粘贴需为当前应用授予 macOS 辅助功能权限。
