# 快捷键参考

## 默认全局快捷键

| 快捷键 | 功能 |
|---|---|
| ⇧⌘V | 显示 / 隐藏剪贴板面板 |
| ⌘; | 粘贴队列中的下一条 |
| ⌘' | 合并并粘贴队列内容 |
| ⌥W | 显示 / 隐藏小组件 |
| ⌥1–⌥5 | 快速粘贴小组件条目 |

在「设置 → 快捷键」和「设置 → 小组件」中可以调整。注册冲突时会提示更换组合。自动粘贴需要 macOS 辅助功能权限。

## 面板内

| 快捷键 | 功能 |
|---|---|
| ⌘1–⌘9 | 快速粘贴对应条目 |
| ↑ / ↓ | 移动选中项 |
| Enter | 粘贴选中项 |
| Esc | 关闭面板 |
| ⌘F | 显示 / 隐藏筛选 |
| D | 删除选中项（搜索输入框外） |
