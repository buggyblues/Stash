# 剪贴板管理

Stash 在后台记录复制内容，按 **⇧⌘V** 打开面板。使用搜索、内容类型、来源应用和标签筛选历史记录。

## 选择与粘贴

| 操作 | 功能 |
|---|---|
| 方向键 | 移动选中项 |
| Enter | 粘贴选中项 |
| ⌘1–⌘9 | 快速粘贴对应条目 |
| Esc | 关闭面板 |
| ⌘F | 显示 / 隐藏筛选 |

自动粘贴到其他应用需要辅助功能权限。文本、图片、代码、JSON、URL、颜色、Base64 和文件路径都有对应预览。

## 整理历史

收藏常用内容，置顶需要长期保留的条目，或用标签整理内容。在通用设置中调整保留天数与最大记录数；自动清理会保护收藏与置顶记录。

## 序列与批量粘贴

将条目加入队列后，按 **⌘;** 依次粘贴，或按 **⌘'** 合并队列内容后粘贴。快捷键可在设置中调整。

## 小组件

按 **⌥W** 显示桌面小组件，用 **⌥1–⌥5** 快速粘贴其中的内容。小组件可以固定显示，并跟随主面板的筛选条件。

## iCloud Drive

在「设置 → 同步」中启用可选 iCloud Drive 同步。数据默认保存在本机；同步需要本机 iCloud Drive 可用。
